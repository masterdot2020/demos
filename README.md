# demos

Lee Cee's public demos, hosted free on GitHub Pages: https://masterdot2020.github.io/demos/

- One folder per demo, each with its own `index.html`. Add a link to it in the root `index.html`.
- Everything here is public. Nothing private, no client work under NDA, no keys.
- Static files only (HTML, CSS, JS, images, video). Keep each file under 100 MB; prefer small.
