Same effect in After Effects or TouchDesigner

After Effects

  1. Footage layer: slow handheld macro of a surface.
  2. Map precomp, switched off: a white shape on black. Rounded rectangle plus Fast Box Blur for rings, Gradient Ramp for slit-scan, a 3D layer's depth pass for the slab. Add Effect › Stylize › Posterize (Level 12–20) for hard bands.
  3. On the footage: Effect › Time › Time Displacement. Map layer = the precomp, Max Displacement Time 1.2 s, Time Resolution 60, Stretch Map to Fit.
  4. Fringes: duplicate twice, nudge Max Displacement Time 1–2 frames on each copy, keep one colour per copy with Shift Channels, set the copies to Add.
  5. Streaks: on a duplicate, mask a 1 px row and scale it up on Y.

TouchDesigner

Cache the last 72 frames into a Texture 3D TOP and drive a Time Machine TOP with a blurred Rectangle, Circle or Ramp TOP as the time map.
